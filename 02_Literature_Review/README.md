# 02_Literature_Review

This folder provides the GitHub evidence for Chapter 2 (Literature Review) of the
Research Proposal, as required by the Assignment 2 brief:

> *Literature Review Supporting Materials — 02_Literature_Review/: Literature review
> analysis table • Comparison of existing techniques • Research gap analysis • Summary
> of methods/algorithms identified from previous studies • Relevant datasets •
> Evaluation metrics identified from previous research • References supporting the
> proposed methodology. The content must be consistent with Chapter 2 of the Research
> Proposal.*

Every file below is written to match Chapter 2 of the group's Research Proposal
word-for-word in substance (same theme names, same study counts — 17/19/8/10 out of the
50 papers reviewed in Assignment 1 — same Table 2.1, and the same five research gaps,
Sections 2.8.1-2.8.5).
